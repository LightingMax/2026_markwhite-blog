一段视频里的手把杯子举起，另一段把杯子放下。单独看其中一帧，画面可能很相似；要分辨动作，我们需要知道画面**如何随时间变化**。

TSM（Temporal Shift Module，时间位移模块）提供了一种轻量的办法：**沿时间轴移动部分特征通道，让相邻帧的信息在后续 2D 卷积中相遇**。它搬动的是某个通道对应的整张特征图，而不是挑选原图中的几个像素。

## 1. 首先理解：什么是 Channel？

先看一张 RGB 彩色图片。它并不是在每个位置存放一个“颜色名字”，而是在每个像素位置存放三个数：R、G、B，分别表示红、绿、蓝分量。

把所有位置的 R 数值单独取出来，就得到一张二维矩阵；G 和 B 也一样。这三张二维矩阵，就是原图的三个 **Channel（通道）**。

<RGBChannelDiagram />

树形图里的两种显示方式容易让人混淆：只点亮 R 分量时，图片看起来是红黑色；把同一组数值映射成灰度，它就变成黑白图。**通道存储的是数值，显示成什么颜色是可视化时的选择。** 例如某个位置的 RGB 为 `(200, 80, 30)`，那么 R、G、B 三张矩阵在这个位置分别存放 200、80、30。

假设原图尺寸是 $224 \times 224$，那么整个输入张量是：

<div className="tsm-equation">

$X \in \mathbb{R}^{3 \times 224 \times 224}$

</div>

### 经过卷积，为什么从 3 个通道变成 64 个？

卷积层可以设置 64 个卷积核。第一层中的每个卷积核会同时读取 R、G、B 三个输入通道，在各个空间位置计算响应，产生一张输出特征图。64 个卷积核就产生 64 张特征图。如果这层把空间尺寸降到 $112 \times 112$，输出就是：

<div className="tsm-equation">

$F \in \mathbb{R}^{64 \times 112 \times 112}$

</div>

这三个数字要分开读：**64 张特征图，每张有 112 行、112 列。** 例如第 0 个通道是 $F[0,:,:]$，它是一张 $112 \times 112$ 的二维矩阵；而 $F[0,20,30]$ 只是这张矩阵中一个位置的数值。

| 看到的对象 | 代表什么 |
| --- | --- |
| RGB 原图的一个通道 | 同一颜色分量在所有空间位置上的数值 |
| 卷积输出的一个通道 | 某个卷积核在所有空间位置上的响应 |
| 64 个输出通道 | 64 种响应组成的完整特征张量 |

**单张特征图确实只表示某一种响应；这里的“部分信息”，不是指原图的一块裁剪。** 一张通道图仍覆盖整个输出空间网格，只是对它学到的模式反应强，对其他内容反应弱；它不是一张完整的原图副本。浅层可能突出某些边缘、颜色或纹理，深层则可能响应更复杂的组合，也不能保证每个通道都能用一句语义来命名。

下面的实验可以展开 64 张真实特征图，对照观察同一输入经过不同卷积核后得到的不同响应。**TSM 搬动的，是其中某张二维矩阵的全部数值。**

## 2. 逐帧处理为什么不够？

从视频采样 8 帧，暂时忽略 batch 维度，输入形状是 $8 \times 3 \times 224 \times 224$。经过一些卷积层后，特征可能变成 $8 \times 64 \times 112 \times 112$：每帧都有 64 个特征通道。

普通 2D 卷积独立处理每一帧，在卷积过程中不直接交换帧间信息。后续当然可以另加时序模块或聚合方式；但如果只对逐帧特征做不考虑顺序的聚合，就难以区分举起和放下这类画面相近、时间顺序不同的动作。

## 3. 亲手模拟一次位移

先用 8 个通道把操作写清楚，再看真实特征图。假设每帧只有 A 到 H 共 8 个通道，第 4 帧位移前为：

<div className="tsm-equation">

$[A_4, B_4, C_4, D_4, E_4, F_4, G_4, H_4]$

</div>

把 A 通道从后一帧移入，把 B 通道从前一帧移入，其余通道留在原处。每个字母都代表一整张二维特征图：

<div className="tsm-equation">

$[A_5, B_3, C_4, D_4, E_4, F_4, G_4, H_4]$

</div>

### 看真实特征图怎样迁移

下面不再用字母方块代替图像，而是运行 ImageNet 预训练 ResNet18，取得第一层 `conv1 → BN → ReLU` 的真实输出：每帧 64 张 $112 \times 112$ 特征图。这里在浅层特征上演示位移，便于看清响应；论文中的 TSM 可插入残差分支，并不限定在这个展示位置。

操作时先选择 **C0**，点击“执行整张特征图迁移”，观察后一帧的完整响应图落到当前帧；再试 **C8**，它从前一帧移入；**C16** 则留在本帧。选择第 1 或第 8 帧，可以看到缺失邻帧时的全零矩阵。

<TemporalShiftDemo />

**看的是整张响应图换了来源，不是图里的亮点被单独挪动。** 以当前帧 F4 的 C0 为例：位移前是 F4 的 C0；位移后是 F5 的 C0，矩阵内的 112 × 112 个数值全部来自 F5，而且每个数值的空间坐标保持不变。下一步卷积才会把这些不同时间来源的通道混合起来。

例如，第 4 帧的 A 位置接收第 5 帧的 A，B 位置接收第 3 帧的 B。第 1 帧没有前一帧，第 8 帧没有后一帧，示例中对应位置用零填充。方向描述以**特征流动方向**和**当前帧从哪里取值**为准：从后一帧取值，就是特征向过去移动。

论文常用的双向设置将总共四分之一通道移动：八分之一向过去、八分之一向未来，其余四分之三保持不动。字母示例的 8 通道正好对应这个比例；真实 64 通道实验中，C0–C7 从后一帧移入，C8–C15 从前一帧移入，C16–C63 保持本帧，总共仍是 1/4 通道移动。

## 4. 移动之后，为什么有助于识别动作？

TSM 本身只重新排列特征，不计算帧差或融合特征。融合由后面的卷积完成。忽略空间维度，假设当前帧某个位置的输入是 $[A_5, B_3, C_4, \ldots]$，一个 $1 \times 1$ 卷积的输出可以写成：

<div className="tsm-equation">

$Y_4 = w_1 A_5 + w_2 B_3 + w_3 C_4 + \cdots$

</div>

这里的权重通过训练学习。一次普通的通道混合，便能组合来自不同时刻的特征；更大空间卷积核以及多层网络还可以组合邻近空间位置的信息。多次位移和卷积堆叠后，信息也可以跨越更长的时间范围。

这创造了学习时序模式的条件，并不保证某个通道一定表示速度或方向。网络能学到什么，仍取决于结构、训练数据和任务目标。TSM 也没有显式计算光流。

## 5. 用 PyTorch 表示

下面是教学用的双向版本，输入和输出形状都是 `[B, T, C, H, W]`：

```python
import torch


def temporal_shift(x):
    # x: [B, T, C, H, W]
    _, _, channels, _, _ = x.shape
    fold = channels // 8
    out = torch.zeros_like(x)

    # 当前帧从后一帧取特征，特征向过去移动
    out[:, :-1, :fold] = x[:, 1:, :fold]
    # 当前帧从前一帧取特征，特征向未来移动
    out[:, 1:, fold:2 * fold] = x[:, :-1, fold:2 * fold]
    # 其余通道保持不变
    out[:, :, 2 * fold:] = x[:, :, 2 * fold:]
    return out
```

切片 `x[:, 1:, :fold]` 保留了末尾的整个 `H × W` 空间维度，因此移动的是整张特征图。零初始化同时处理了边界；当通道数小于 8 时，`fold` 为 0，示例不会移动任何通道。

这是便于理解的实现，并未展示残差块集成、在线推理缓存或性能优化。TSM 不引入需要学习的位移参数和额外乘加运算，但实际实现仍有内存读写和数据搬运开销。

## 6. TSM 与目标跟踪有什么区别？

| 问题 | 关键任务 |
| --- | --- |
| 目标检测 | 这一帧有什么目标，在哪里？ |
| 多目标跟踪 | 不同帧中的哪个目标是同一个对象？ |
| 动作识别 | 连续帧中发生了什么动作？ |
| TSM | 让特征提取网络交换时间信息 |

TSM 最初主要用于视频动作识别，是一个可嵌入网络的时间建模模块，不是完整的跟踪算法。论文也讨论了将位移放进 ResNet 残差分支的设计：保留 identity shortcut，让当前帧信息可以沿捷径传递，减轻位移对空间特征的影响。

## 7. 留一个更深的问题

假设小球在第 1、2、3 帧依次出现在左、中、右。TSM 在相同空间坐标处搬运通道，并不会主动寻找不同帧中小球的对应位置。那么，网络为什么仍有可能学到向右运动？

线索在于：位移后，不同时刻的特征进入同一个网络；后续空间卷积可以在邻域内组合这些特征，堆叠的层进一步扩大时空感受野。它可能学到与方向有关的模式，但这种隐式学习不等于显式估计运动或建立目标关联，也不保证对所有速度、位移和遮挡都有效。下一篇可以从这个问题继续展开。
