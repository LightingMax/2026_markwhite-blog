理解色彩问题时，先不要把 JPEG 当作“相机拍到的原始世界”。JPEG 已经是处理链路的末端结果。

一个简化的相机流水线可以写成：

```text
场景光线 → 镜头 → 传感器响应 → 模拟/数字转换 → RAW
       → 黑电平与增益 → 去马赛克 → 白平衡
       → 颜色变换 → 色调映射 → 压缩与显示
```

每一步都在改变数据的含义。传感器记录的是带有光谱响应的电信号，RAW 通常仍然保留了 CFA（彩色滤光片阵列）采样后的数值；而我们熟悉的 RGB 图像，已经经过插值和颜色空间变换。

## 为什么这条链路重要

当我们比较两张照片的颜色时，差异可能来自光源、相机响应、曝光、白平衡算法，也可能只是显示空间不同。如果跳过流水线，很多“颜色偏了”的判断会混合多个原因。

后续章节会分别讨论 RAW 的数据含义、白平衡的估计问题，以及颜色空间如何连接相机和显示设备。
