一张照片不是对世界的直接抄录。光线经过材料、镜头、传感器、ISP、颜色空间和编码，才成为屏幕上的像素。

这套 9 篇文章从颜色科学和相机测量开始，逐步进入 RAW、白平衡、照片风格、计算机视觉中的颜色误区，以及可运行的 Python 实验。文章保留了原始图注和来源说明；配套图像与实验代码也随仓库公开。
