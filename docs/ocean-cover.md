# 海面封面

首页在普通 HTML 标题与文章入口下叠加一个原生 WebGL 画布。海浪、天空和水下颜色均由项目内的 GLSL 生成，无 3D 引擎、外部纹理、视频或 CDN 请求。

## 交互

- 初始镜头位于海面上，随正常页面滚动下降，穿过水面后向上看波面。
- `进入文章` 直接打开 `/blog/docs/`；`跳过封面` 跳到首页文章区。
- `暂停海浪` 冻结时间动画，仍允许通过滚动浏览封面。
- 浅色/深色主题同时调整天空、反光和水下亮度。
- `prefers-reduced-motion: reduce` 时渲染静止海面，取消潜入与平滑滚动，并缩短封面。
- 禁用 JavaScript、WebGL 初始化失败或 context 丢失时显示仓库内 SVG 海面。

## 性能边界

`components/ocean/scene.ts`：一个全屏三角形，一个绘制调用，无离屏 render target。四组方向波及高频法线近似海水，近水线使用最多 16 次局部梯度引导采样和实际变号判断，再细化交点，以减少命中错误波峰的跳变；反射和折射均为着色器近似，并非完整流体模拟。

`components/ocean/hero.tsx`：GLSL 模块延迟导入；桌面目标最多 45 帧/秒，窄屏/触控设备最多 30 帧/秒。画布分别限制为 95 万/38 万像素、DPR 1.35/1；持续慢帧会进一步降低分辨率。实际帧率取决于设备和浏览器。

离开封面、切到后台时取消 RAF；恢复时继续。滚动进度与主题写入 uniform/CSS 变量，不逐帧触发 React render。卸载时释放事件、observer、shader、program 和 buffer，支持 Strict Mode 重挂载。

## 验证

- `npm run lint`
- `npm run types:check`
- `npm run build`
- 浏览器检查：桌面日间/夜间、海面/水下、暂停/继续、跳过封面、窄屏与矮窗口，以及导航/搜索/正文。
- 近水线求交数值抽查：6 组时间、1,275 条射线，对比密集采样，未出现距离最近交点超过 1 米的误差、漏判或切线误判；这是抽样检查，并非所有视角的精确几何保证。

TypeScript 固定在 6.x，以兼容当前 `eslint-config-next` 使用的 `typescript-eslint`；此前 7.x 会导致 lint 在运行前直接失败。
