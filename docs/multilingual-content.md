# 多语言内容与目录

中文 URL 保持 `/docs/…`；英文使用 `/en/docs/…`。静态构建不需要服务器语言重写。

同一目录下的 `article.mdx`（中文）与 `article.en.mdx`（英文）共享文件主名和文章身份。添加译文后，语言切换自动跳到对应文章。仅有中文的文章不会出现在英文目录、首页索引或搜索中：source 使用 `fallbackLanguage: null`。

现有 CVAT 文章沿用 `cvat-video-annotation-zh` 文件主名以保持中文链接稳定，英文原始链接保留跳转入口。无需另外维护翻译关系表。

`navTitle` 是侧栏短标题，正文仍显示完整 `title`。`meta.json` 与 `meta.en.json` 分别定义栏目顺序；专题默认收起，进入文章后自动展开所在分支。不要把 `index` 再放进子文件列表：它已经是文件夹入口。

语言切换找不到译文时进入目标语言文章索引并提示缺少译文。新增语言需扩展 `lib/i18n.ts`、根布局和语言选项，并提供对应的栏目索引。
